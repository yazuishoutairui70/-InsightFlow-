FIRST TIME SETUP

第一次只要做一次

  1. 安装工具安装 Python 环境管理工具 uv 和 Node.js。
  2. 获取 MediaCrawler从原仓库克隆后执行 uv sync。
  3. 本地扫码登录运行下方指令，在打开的浏览器里自行确认登录。
  4. 导出 CSV / JSONL回到本页导入，内容自动带进 AI 分析页。

IMPORT TO INSIGHTFLOW

导入你的导出文件

支持 MediaCrawler 导出的 CSV、JSON、JSONL、TXT 或 Markdown。文件会先在当前浏览器读取，再带到 AI 分析页；最多导入 15,000 个字符，超出部分会按行截取。
