FIRST TIME SETUP

第一次只要做一次

  1. 安装工具安装 uv、Node.js 和 Git。
  2. 获取 MediaCrawler从原仓库克隆后执行 uv sync。
  3. 开启 Chrome 调试访问 chrome://inspect/#remote-debugging，允许本机调试并确认端口 9222 运行中。
  4. 运行并登录在 PowerShell 中进入 MediaCrawler 目录，运行命令并自行扫码。
  5. 导出 CSV / JSONL在 data 目录找到文件，回本页导入。
