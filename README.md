# InsightFlow · 竞品拆解助手 V1 演示版

一个完全静态、无需登录或 API 的桌面端 Web MVP。三条预置路径：小红书（购物 App）、优衣库（服饰零售品牌，适配品牌模板）、Manner Coffee（线下实体品牌）。

## 运行

推荐使用本地 HTTP 服务，以支持 ES Modules：

```bash
python -m http.server 8000
```

在浏览器打开 `http://localhost:8000`。也可以使用 VS Code Live Server。无需安装依赖，手机尺寸也可浏览，但主要按电脑端设计。

## 可体验流程

项目中心 → 新建分析 → 选择预置案例 → 一键载入 → 分析总览 → 模块拆解 → 评论洞察（语言/情绪/主题/搜索）→ 策略洞察（收藏与证据抽屉）→ 报告（复制/下载 Markdown/打印或存 PDF）。

代码结构：`index.html` 页面入口，`styles.css` 视觉样式，`data.js` 三套人工编写的演示数据，`app.js` 路由和交互。

## 数据边界

本版的“观察卡”和中英评论全为演示而编写。评论不是从平台采集的真实评价，情绪分布不能推断真实市场情况；待验证的经营假设也没有真实埋点、销售或门店数据支撑。报告中保留这一说明。**请勿把演示内容作为真实品牌研究成果对外引用。**

V1 当前不支持自由输入产品、网页自动采集、真实评论上传分析或模型生成；这些属于后续可用型 MVP。
